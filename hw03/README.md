# ECE 361 – Homework 3

## Description
This homework is about pointers in C. I created four functions to swap values, find minimum and maximum values, find a value above a threshold, and reverse an array.

## Files
- `ptr.h` – Function declarations.
- `ptr.c` – Pointer functions.
- `tests/test_ptr.c` – Tests for the functions.
- `Makefile` – Builds and tests the program.

## How to Build
Run:

`make`

## How to Test
Run:

`make test`

All 10 tests passed.

## How to Clean
Run:

`make clean`
